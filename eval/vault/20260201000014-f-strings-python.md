## O que é
Strings literais com prefixo `f` que avaliam expressões dentro de `{}`. Disponíveis desde o Python 3.6.

## Sintaxe
```python
f"{variavel}"
f"{valor:.2f}"        # 2 casas decimais
f"{numero:,}"         # separador de milhar
f"{texto:>10}"        # alinha à direita em 10 colunas
f"{x=}"               # depuração: imprime 'x=<valor>' (3.8+)
```

## Exemplo
```python
nome, total = "Ana", 1234.5
print(f"{nome} gastou R$ {total:,.2f}")   # Ana gastou R$ 1,234.50
```

## Gotchas
- Para escrever chaves literais, duplique: `f"{{chave}}"`.
- Antes do 3.12 não dava para reutilizar o mesmo tipo de aspas dentro da expressão: `f"{d["k"]}"` só funciona a partir do 3.12.
