## O que é
Retorna **todas** as linhas da tabela da esquerda e as correspondentes da direita. Quando não há correspondência, as colunas da direita vêm como `NULL`.

## Sintaxe
```sql
SELECT a.col, b.col
FROM esquerda a
LEFT JOIN direita b ON a.id = b.a_id;
```

## Exemplo
```sql
-- clientes que nunca compraram
SELECT c.nome
FROM clientes c
LEFT JOIN pedidos p ON p.cliente_id = c.id
WHERE p.id IS NULL;
```

## Gotchas
- Filtro sobre a tabela da direita no `WHERE` (ex.: `WHERE p.status = 'pago'`) descarta as linhas com `NULL` e transforma o LEFT JOIN num INNER JOIN na prática. Coloque a condição no `ON`: `LEFT JOIN pedidos p ON p.cliente_id = c.id AND p.status = 'pago'`.
- `RIGHT JOIN` é o espelho; quase sempre dá para reescrever como LEFT JOIN trocando a ordem das tabelas.
