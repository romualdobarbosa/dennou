## O que faz
Guarda temporariamente as alterações não commitadas (staged e não staged) numa pilha e deixa o diretório de trabalho limpo, para trocar de branch ou puxar atualizações.

## Uso
```bash
git stash                 # guarda
git stash list            # lista
git stash pop             # reaplica o mais recente e remove da pilha
git stash apply stash@{1} # reaplica sem remover
git stash drop stash@{0}  # descarta um item
```

## Flags úteis
- `-u` — inclui arquivos não rastreados.
- `-m "descrição"` — dá nome ao stash (`git stash push -m`).
- `git stash show -p` — mostra o diff guardado.

## Exemplo
```bash
git stash -u -m "wip formulário"
git switch hotfix
# ...
git switch -
git stash pop
```

Se o `pop` der conflito, o item **não** é removido da pilha; resolva e rode `git stash drop`.
