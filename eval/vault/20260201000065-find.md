## O que faz
Percorre uma árvore de diretórios e lista os arquivos que satisfazem critérios como nome, tipo, tamanho, data de modificação e permissões. Também pode executar uma ação sobre cada resultado.

## Uso
```bash
find <onde> <critérios> <ação>
find . -name "*.log"
```

## Flags úteis
- `-name "*.txt"` / `-iname` — por nome (glob), com ou sem distinguir maiúsculas. Coloque o padrão entre aspas para o shell não expandir antes.
- `-type f` / `-type d` / `-type l` — só arquivos, diretórios ou links.
- `-mtime +7` — modificados há **mais** de 7 dias; `-mtime -1` — nas últimas 24 horas. `-mmin` faz o mesmo em minutos.
- `-size +100M` — maiores que 100 MiB.
- `-maxdepth 2` — limita a profundidade (deve vir antes dos outros testes).
- `-empty` — arquivos ou diretórios vazios.
- `-user ana`, `-perm -u+x` — por dono e por permissão.
- `-delete` — apaga o que foi encontrado.
- `-exec cmd {} \;` — roda o comando uma vez **por arquivo**.
- `-exec cmd {} +` — roda o comando passando **vários arquivos de uma vez**, bem mais rápido.

## Exemplo
```bash
# apagar logs com mais de 30 dias
find /var/log/app -name "*.log" -mtime +30 -delete

# os 10 maiores arquivos acima de 100 MB no home
find ~ -type f -size +100M -exec du -h {} + | sort -rh | head -10

# corrigir permissões: diretórios 755, arquivos 644
find site/ -type d -exec chmod 755 {} +
find site/ -type f -exec chmod 644 {} +

# nomes com espaço passados com segurança para outro comando
find . -name "*.tmp" -print0 | xargs -0 rm
```

Dicas:
- Teste sempre sem `-delete` primeiro para ver o que seria apagado. A posição importa: `-delete` antes dos filtros apaga tudo o que for percorrido.
- Critérios em sequência são combinados com E. Para OU, use `-o` com parênteses escapados: `find . \( -name "*.jpg" -o -name "*.png" \)`.
- Para busca rápida só por nome em todo o sistema, `locate` usa um índice pré-construído e responde na hora, mas pode estar desatualizado até o próximo `updatedb`.
