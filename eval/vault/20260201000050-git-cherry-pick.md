## O que faz
Aplica as mudanças de um ou mais commits específicos, de qualquer branch, no branch atual, criando commits novos.

## Uso
```bash
git cherry-pick <sha>
git cherry-pick <sha1> <sha2>
git cherry-pick A^..B       # intervalo de A até B, inclusive
```

## Flags úteis
- `-x` — acrescenta "(cherry picked from commit ...)" na mensagem.
- `-n` — aplica sem commitar.
- `--continue` / `--abort` — depois de resolver conflito ou para desistir.

## Exemplo
```bash
# levar a correção feita em develop para o branch de release
git switch release/2.1
git cherry-pick -x 4e5f6a7
```

Usar cherry-pick demais entre branches que depois serão mergeados gera commits duplicados com hashes diferentes.
