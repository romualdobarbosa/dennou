## Erro
```
KeyError: 'email'
```

## Causa
Acesso com colchetes `d["email"]` a uma chave que não existe no dicionário.

## Solução
```python
email = usuario.get("email")              # None se não existir
email = usuario.get("email", "sem email") # padrão
if "email" in usuario:
    ...
from collections import defaultdict
grupos = defaultdict(list)                # cria a lista na primeira vez
```

## Contexto
Comum ao ler JSON de APIs em que alguns campos são opcionais. Erros de digitação e diferença de maiúsculas/minúsculas na chave também causam o erro.
