## O que faz
Procura linhas que casam com um padrão (texto ou expressão regular) em arquivos ou na entrada padrão.

## Uso
```bash
grep "padrão" arquivo
comando | grep "padrão"
```

## Flags úteis
- `-i` — ignora maiúsculas/minúsculas.
- `-r` — busca recursiva em diretórios.
- `-n` — mostra o número da linha.
- `-v` — inverte: linhas que **não** casam.
- `-l` — só os nomes dos arquivos.
- `-c` — conta as linhas que casam.
- `-w` — palavra inteira.
- `-E` — regex estendida (`a|b`, `+`, `?`).
- `-o` — mostra só o trecho que casou.

## Exemplo
```bash
grep -rn --include="*.py" "TODO" src/
grep -E "ERROR|WARN" app.log | grep -v "healthcheck"
```
