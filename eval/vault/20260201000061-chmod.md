## O que faz
Altera as permissões de leitura (r), escrita (w) e execução (x) de arquivos e diretórios para o dono (u), o grupo (g) e os outros (o).

## Uso
```bash
chmod 755 script.sh        # notação octal
chmod u+x script.sh        # notação simbólica
chmod go-w arquivo.txt
```

## Flags úteis
- `-R` — aplica recursivamente.
- `-v` — mostra cada alteração.
- `X` maiúsculo (simbólico) — dá execução só a diretórios e a arquivos que já são executáveis por alguém: `chmod -R a+rX pasta/`.

## Exemplo
```bash
chmod 644 config.yml   # rw-r--r--  dono lê e escreve; resto só lê
chmod 755 deploy.sh    # rwxr-xr-x  todos executam; só o dono altera
chmod 600 ~/.ssh/id_ed25519
```

Cada dígito octal soma r=4, w=2, x=1, na ordem dono, grupo, outros. Para trocar o **dono** do arquivo, o comando é outro: `chown`.
