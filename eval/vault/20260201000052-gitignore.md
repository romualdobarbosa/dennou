## O que é
Arquivo com padrões de caminhos que o Git deve ignorar ao listar arquivos não rastreados e ao fazer `git add`.

## Sintaxe
```gitignore
*.log            # qualquer .log em qualquer pasta
build/           # só diretórios chamados build
/config.local    # só na raiz do repositório
**/temp          # temp em qualquer profundidade
!importante.log  # exceção: não ignorar este
```

## Exemplo
```gitignore
__pycache__/
.venv/
.env
*.sqlite3
```

## Gotchas
- `.gitignore` não afeta arquivos **já rastreados**. Para parar de versionar mantendo o arquivo local: `git rm --cached arquivo` e commit.
- `git check-ignore -v arquivo` mostra qual regra está ignorando o arquivo.
- Ignores pessoais (do editor, do sistema) vão em `.git/info/exclude` ou no arquivo global configurado em `core.excludesFile`.
