## O que é
`WHERE` filtra **linhas individuais** antes de qualquer agrupamento. Só as linhas que satisfazem a condição seguem para o `GROUP BY`, o `SELECT` e o `ORDER BY`.

## Sintaxe
```sql
SELECT * FROM pedidos
WHERE status = 'pago'
  AND valor BETWEEN 100 AND 500
  AND cidade IN ('Recife', 'Natal')
  AND nome LIKE 'A%';
```

## Exemplo
```sql
SELECT cliente_id, valor
FROM pedidos
WHERE criado_em >= '2026-01-01';
```

## Gotchas
- Não aceita funções de agregação: `WHERE COUNT(*) > 5` é erro. Para filtrar grupos, use `HAVING`.
- Não enxerga aliases definidos no `SELECT`, porque é avaliado antes dele.
- `coluna = NULL` nunca é verdadeiro; use `IS NULL`.
