## Resposta
O arquivo `/etc/sudoers` deve ser editado com `sudo visudo`, que trava o arquivo contra edições simultâneas e **valida a sintaxe antes de salvar**. Um erro de sintaxe salvo direto no arquivo faz o `sudo` parar de funcionar para todos, e aí você perde justamente a ferramenta necessária para consertar.

## Contexto
```bash
sudo visudo                              # edita /etc/sudoers
sudo visudo -f /etc/sudoers.d/deploy     # arquivo separado, preferível
sudo -l                                  # o que o usuário atual pode rodar
```

```text
deploy ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart app
```

Para dar acesso total, normalmente basta adicionar o usuário ao grupo administrativo: `sudo` no Debian/Ubuntu, `wheel` no Fedora/RHEL (`usermod -aG wheel nome`).

## Fonte
Manual do sudoers (`man sudoers`) e do visudo.
