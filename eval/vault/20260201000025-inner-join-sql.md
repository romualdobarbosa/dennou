## O que é
Combina linhas de duas tabelas e retorna **apenas** os pares em que a condição do `ON` é verdadeira. Linhas sem correspondência dos dois lados são descartadas. `JOIN` sozinho é o mesmo que `INNER JOIN`.

## Sintaxe
```sql
SELECT a.col, b.col
FROM tabela_a a
INNER JOIN tabela_b b ON a.id = b.a_id;
```

## Exemplo
```sql
SELECT p.id, c.nome
FROM pedidos p
JOIN clientes c ON c.id = p.cliente_id;
```

## Gotchas
- Se a chave se repete do outro lado, as linhas se multiplicam (um pedido com 3 itens vira 3 linhas). Isso infla `SUM` e `COUNT` feitos depois do join.
- Esquecer o `ON` (ou usar `CROSS JOIN`) gera o produto cartesiano.
