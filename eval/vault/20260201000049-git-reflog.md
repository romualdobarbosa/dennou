## O que faz
Mostra o histórico local de por onde o HEAD (e cada branch) passou: commits, checkouts, resets, rebases, merges. Serve para **recuperar commits que parecem perdidos** depois de um `reset --hard`, um rebase errado ou um branch apagado.

## Uso
```bash
git reflog
git reflog show feature/x
```

## Flags úteis
- `HEAD@{n}` — referência à n-ésima posição anterior do HEAD.
- `--date=iso` — mostra quando cada movimento aconteceu.

## Exemplo
```bash
git reflog
# 3f2a1b0 HEAD@{0}: reset: moving to HEAD~3
# 9c8d7e6 HEAD@{1}: commit: finaliza relatório
git reset --hard HEAD@{1}         # volta ao estado antes do reset
git branch resgate 9c8d7e6        # ou cria um branch apontando para o commit
```

O reflog é só local. Por padrão as entradas expiram em 90 dias (30 dias para commits inalcançáveis) e depois o `git gc` pode apagar esses commits.
