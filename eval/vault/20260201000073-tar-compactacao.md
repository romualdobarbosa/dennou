## O que faz
Junta vários arquivos e diretórios num único arquivo `.tar` e, opcionalmente, comprime com gzip, bzip2, xz ou zstd.

## Uso
```bash
tar -czf backup.tar.gz pasta/     # criar .tar.gz
tar -xzf backup.tar.gz            # extrair
tar -tzf backup.tar.gz            # listar conteúdo sem extrair
```

## Flags úteis
- `-c` criar, `-x` extrair, `-t` listar.
- `-f arquivo` — nome do arquivo tar (vem por último no grupo de letras).
- `-z` gzip, `-j` bzip2, `-J` xz, `--zstd` zstd.
- `-v` — lista os arquivos processados.
- `-C dir` — extrai em outro diretório.
- `--exclude="*.log"` — ignora padrões.

## Exemplo
```bash
tar -xf release.tar.xz -C /opt/app    # GNU tar detecta a compressão sozinho ao extrair
tar -czf site-$(date +%F).tar.gz --exclude=node_modules site/
```
