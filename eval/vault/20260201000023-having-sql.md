## O que é
`HAVING` filtra **grupos** depois do `GROUP BY`, usando o resultado das funções de agregação. É o "WHERE dos grupos".

## Sintaxe
```sql
SELECT coluna, AGG(outra)
FROM tabela
GROUP BY coluna
HAVING AGG(outra) > valor;
```

## Exemplo
```sql
-- clientes com mais de 3 pedidos pagos
SELECT cliente_id, COUNT(*) AS qtd
FROM pedidos
WHERE status = 'pago'        -- filtra linhas antes
GROUP BY cliente_id
HAVING COUNT(*) > 3;         -- filtra grupos depois
```

## Gotchas
- Condições que não dependem de agregação devem ir no `WHERE`: filtrar antes reduz o volume agrupado.
- MySQL e SQLite aceitam o alias do `SELECT` no `HAVING` (`HAVING qtd > 3`); o PostgreSQL não, lá é preciso repetir a expressão `COUNT(*)`.
