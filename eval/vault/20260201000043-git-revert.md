## O que faz
Cria um **novo commit** que aplica o inverso das mudanças de um commit anterior. O histórico não é reescrito, então é a forma segura de desfazer algo que já foi enviado para um branch compartilhado.

## Uso
```bash
git revert <sha>
```

## Flags úteis
- `--no-edit` — usa a mensagem padrão ("Revert ...").
- `--no-commit` (`-n`) — aplica a reversão sem commitar; útil para reverter vários commits num só.
- `-m 1` — necessário para reverter um commit de merge, indicando qual pai é a linha principal.

## Exemplo
```bash
git log --oneline -3
git revert a1b2c3d
git push
```

Reverter o próprio commit de revert reaplica a mudança original.
