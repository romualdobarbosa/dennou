## O que é
Coleção não ordenada de elementos **únicos**. Teste de pertencimento (`in`) é O(1) em média.

## Sintaxe
```python
s = {1, 2, 3}
vazio = set()          # {} cria um dict, não um set
s.add(4)
s.discard(10)          # não dá erro se não existir
a | b   # união
a & b   # interseção
a - b   # diferença
```

## Exemplo
```python
emails = ["x@a.com", "y@a.com", "x@a.com"]
unicos = set(emails)   # remove duplicados
```

## Gotchas
- `set(lista)` perde a ordem original. Para deduplicar mantendo a ordem: `list(dict.fromkeys(lista))`.
- `remove()` levanta `KeyError` se o item não existir; `discard()` não.
