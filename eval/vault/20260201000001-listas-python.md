## O que é
Sequência ordenada e **mutável**. Aceita elementos de tipos diferentes e cresce ou encolhe em tempo de execução.

## Sintaxe
```python
nums = [3, 1, 2]
nums.append(4)        # adiciona no fim
nums.insert(0, 9)     # adiciona na posição 0
nums.pop()            # remove e retorna o último
nums[1:3]             # fatia (slice)
```

## Exemplo
```python
frutas = ["maçã", "banana"]
frutas.append("uva")
frutas[0] = "pera"    # pode alterar no lugar
print(frutas)         # ['pera', 'banana', 'uva']
```

## Gotchas
- `b = a` não copia a lista: os dois nomes apontam pro mesmo objeto. Use `a.copy()` ou `a[:]`.
- Lista não pode ser chave de dicionário porque não é hashable.
- Se os dados não vão mudar, uma tupla comunica melhor a intenção.
