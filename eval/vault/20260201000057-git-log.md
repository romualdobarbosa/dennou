## O que faz
Lista os commits do histórico, com várias opções de formato e filtro.

## Uso
```bash
git log --oneline --graph --all --decorate
```

## Flags úteis
- `--oneline` — um commit por linha.
- `--graph` — desenha os branches em ASCII.
- `-p` — mostra o diff de cada commit.
- `--author="nome"`, `--since="2 weeks ago"` — filtram por autor e data.
- `-S "texto"` — commits que adicionaram ou removeram esse texto (pickaxe).
- `--follow arquivo` — segue o histórico mesmo após renomeações.
- `main..feature` — commits que estão em feature e não em main.

## Exemplo
```bash
git log --oneline -S "calcular_frete" -- src/
git log --since="2026-01-01" --stat
```
