## O que é
Sequência ordenada e **imutável**. Depois de criada, não dá pra adicionar, remover ou trocar elementos. Por ser imutável (e se todos os itens forem hashable), pode ser chave de dicionário ou item de set.

## Sintaxe
```python
ponto = (10, 20)
x, y = ponto          # desempacotamento
unico = (5,)          # tupla de um elemento: a vírgula é obrigatória
vazia = ()
```

## Exemplo
```python
def min_max(valores):
    return min(valores), max(valores)   # retorna uma tupla

menor, maior = min_max([4, 8, 1])
```

## Gotchas
- `(5)` é só o inteiro 5 entre parênteses; quem cria a tupla é a vírgula.
- `ponto[0] = 1` levanta `TypeError: 'tuple' object does not support item assignment`.
- A tupla é imutável, mas se contiver uma lista, a lista interna continua mutável.
