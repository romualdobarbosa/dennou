## O que faz
Grava no histórico um snapshot do que está na área de staging (index). Com `--amend`, substitui o último commit por um novo, com as mudanças staged somadas e/ou outra mensagem.

## Uso
```bash
git commit -m "mensagem"
git commit --amend
```

## Flags úteis
- `-m` — mensagem inline.
- `-a` — inclui automaticamente as alterações de arquivos já rastreados (não pega arquivos novos).
- `--amend` — refaz o último commit.
- `--amend --no-edit` — refaz mantendo a mensagem.
- `-v` — mostra o diff no editor enquanto você escreve a mensagem.

## Exemplo
```bash
git commit -m "corrige cálculo de frete"
# esqueci um arquivo:
git add frete_test.py
git commit --amend --no-edit
```

Não use `--amend` em commit que já foi enviado com push: ele gera um commit com outro hash, e o push seguinte exige force.
