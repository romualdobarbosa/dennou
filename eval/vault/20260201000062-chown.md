## O que faz
Muda o **usuário dono** e/ou o **grupo** de arquivos e diretórios. Não mexe nas permissões rwx.

## Uso
```bash
sudo chown usuario arquivo
sudo chown usuario:grupo arquivo
sudo chown :grupo arquivo        # só o grupo (equivale a chgrp)
```

## Flags úteis
- `-R` — recursivo.
- `-h` — altera o próprio link simbólico em vez do alvo.
- `--reference=outro` — copia dono e grupo de outro arquivo.

## Exemplo
```bash
sudo chown -R www-data:www-data /var/www/site
```

Só o root pode trocar o dono de um arquivo. Um usuário comum pode trocar o grupo apenas para um grupo do qual ele faz parte, e só em arquivos que são dele.
